# Customer Behavior Analytics Dashboard

## Short Description

**Customer Behavior Analytics Dashboard** is an interactive **Power BI data analytics project** designed to analyze customer purchasing behavior, sales performance, revenue trends, subscription patterns, demographics, and product-category performance.

The dashboard transforms customer transaction data into actionable insights through KPI cards, interactive slicers, category analysis, demographic comparisons, and revenue visualizations. It helps identify high-performing customer segments, profitable product categories, and purchasing patterns.

## Tech Stack

* **Power BI Desktop** – Dashboard development and interactive data visualization
* **Power Query** – Data cleaning, transformation, and preparation
* **DAX** – KPI calculations, measures, and analytical metrics
* **SQL** – Data extraction, querying, and preprocessing
* **Python (Pandas Library)** – Data cleaning, manipulation, and exploratory data analysis
* **Microsoft Excel / CSV** – Data source and initial data preparation

## Data Source

The project uses a **Customer Shopping Behavior dataset** containing customer-level purchase and demographic information, including:

* Customer ID
* Gender
* Age / Age Group
* Product Category
* Purchase Amount
* Review Rating
* Subscription Status
* Shipping Type
* Sales and revenue-related attributes

The raw data was cleaned and transformed using **SQL and Python (Pandas)** before being modeled and visualized in Power BI.

## Features & Highlights

### 1. Customer KPI Analysis

The dashboard provides high-level performance indicators including:

* **3.9K Customers**
* **$59.76 Average Purchase Amount**
* **3.75 Average Review Rating**

These KPIs provide a quick overview of customer base size, spending behavior, and satisfaction.

### 2. Subscription Analysis

The dashboard analyzes customer subscription behavior using an interactive subscription filter and percentage breakdown.

* Comparison of **Subscribed vs. Non-Subscribed Customers**
* Subscription-based customer segmentation
* Identification of the dominant customer subscription group

### 3. Category Performance

Interactive visualizations analyze revenue and sales across major product categories:

* Clothing
* Accessories
* Footwear
* Outerwear

The dashboard makes it easy to identify the strongest-performing categories based on revenue and sales volume.

### 4. Customer Demographic Analysis

Customer behavior is analyzed across different age segments:

* Young Adult
* Middle-aged
* Adult
* Senior

Separate visualizations compare **revenue and sales by age group**, helping identify the customer segments contributing most to overall performance.

### 5. Gender & Customer Segmentation

Interactive slicers allow users to filter the dashboard by:

* Female
* Male

This enables deeper analysis of purchasing behavior across different customer segments.

### 6. Shipping Analysis

The dashboard incorporates shipping-type segmentation, including:

* 2-Day Shipping
* Express
* Free Shipping

This allows customer behavior and purchasing performance to be analyzed in relation to shipping preferences.

### 7. Interactive Dashboard

The dashboard includes:

* Interactive slicers and filters
* KPI cards
* Donut chart for subscription analysis
* Revenue-by-category chart
* Sales-by-category chart
* Revenue-by-age-group analysis
* Sales-by-age-group analysis
* Cross-filtering for customer segmentation
* Clean, business-focused dashboard layout

## Key Analytical Questions

This dashboard can help answer questions such as:

* Which product category generates the highest revenue?
* Which categories contribute the most sales?
* What percentage of customers have an active subscription?
* Which age group contributes the highest revenue and sales?
* How does purchasing behavior vary by gender?
* What is the average customer purchase amount?
* What is the overall average review rating?
* How can customer segments be identified for targeted business strategies?

## Project Objective

The objective of this project is to demonstrate how **data cleaning, exploratory analysis, KPI development, and interactive visualization** can be used to understand customer behavior and support data-driven business decisions.

The project demonstrates the workflow:

**SQL → Python (Pandas) → Data Cleaning → Data Transformation → Data Modeling → DAX → Visualization → Business Insights**

## Project Outcome

This project showcases an end-to-end **Data Analyst / Business Intelligence workflow** using Power BI to convert customer transaction data into an interactive analytical dashboard.

It demonstrates practical skills in **SQL, Python (Pandas), Power BI, Power Query, DAX, customer segmentation, KPI reporting, demographic analysis, sales analysis, revenue analysis, and data visualization**, making it a strong portfolio project for Data Analyst and Business Intelligence roles.
